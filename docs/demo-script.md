# VeriSight presentation walkthrough

1. **Why it matters (20 sec):** Show the reviewer overview. Point to coverage, open workload, overdue follow-ups, and the fictional site map/list. State that all data is simulated.
2. **Transparent dispatch (50 sec):** Open a pending case and assign it. Explain the eligibility list, high-risk weights, SHA-256 commitment, and append-only event number. Reveal the seed and show the two browser checks: commitment match and selection reproduced.
3. **Field work (90 sec):** Sign in as the selected inspector. Open the assigned case, check in with the clearly labelled seeded demo override, answer the checklist, add a finding, and use the built-in sample image. Show the “Saved on this device — not submitted” state, sync, final review, and submit.
4. **Evidence and oversight (60 sec):** Return as reviewer. Show the server timestamp and SHA-256 hash, geofence result, checklist answers, and plain-language risk flags. Review the finding with a note, create a follow-up, and show the updated dashboard and status history.
5. **Honest boundary (20 sec):** Trigger a simulated remote verification and point out “CCTV unavailable in MVP.” Explain that reproducible local randomness, client location, and hashing do not establish independent trust or production readiness.
